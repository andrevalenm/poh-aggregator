# Salvage v1 — the first research pass

These nineteen write-ups are an earlier, independent salvage of the same primary sources
that [`research/`](../INDEX.md) covers. They were produced in a separate pass, before the
ontology existed, and they use their own filenames — `poh-classics.md` where the current
tree has `poh-landscape-sweep.md`, `scoring-and-prior-art.md` where it has
`prior-art-scoring.md`, and so on.

They are kept for two reasons. The overlapping files were written without reference to each
other, so where two independent readings of the same source agree, that agreement is worth
something. And where they disagree, the disagreement is the interesting part.

**The canonical research is [`research/`](../INDEX.md), not this directory.** Nothing in the
ontology, the weights, or the scoring derives from these files. Read them as a first draft.
